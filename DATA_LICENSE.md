# Data licensing and attribution

The MIT `LICENSE` in this repository applies to the software authored for **Male Fly Connectome AR**. It does **not** relicense third-party connectome data.

## MaleCNS data

MaleCNS v1.0 scientific data are provided by the FlyEM/Janelia collaboration and partners and are documented as licensed under **Creative Commons Attribution (CC BY)**.

Authoritative project pages:

- https://male-cns.janelia.org/
- https://male-cns.janelia.org/download/

Any committed or distributed derivative data under `data/` must preserve:

1. the dataset identifier (`male-cns:v1.0`);
2. provenance describing how the subset was obtained;
3. attribution to the MaleCNS project and associated publication;
4. the applicable CC BY terms;
5. a machine-readable manifest when practical.

## Separation of code and data

- **Code written for this repository:** MIT.
- **MaleCNS-derived neuron morphology/connectivity data:** source CC BY terms.
- **Third-party runtime libraries/models:** their respective upstream licenses and terms.

The project must not imply that the MaleCNS dataset itself is MIT licensed.
